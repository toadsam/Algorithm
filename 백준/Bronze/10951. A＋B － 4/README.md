### 풀이 메모

EOF까지 반복 입력을 받는 문제.

`cin >> a >> b` 후에 eof()를 검사해야 한다. EOF에 도달하면 스트림 상태가 fail이 되면서 변수에 값이 저장되지 않고 이전 루프 값이 남기 때문에, **읽기를 시도한 뒤에** eof를 확인해야 원하는 시점에 true가 된다. 그래서 `(cin >> a >> b).eof()` 형태로 쓴다.
