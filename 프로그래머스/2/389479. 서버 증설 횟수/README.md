### 풀이 메모

핵심은 **need가 '총 서버 대수'가 아니라 '증설 서버 대수'**라는 것.

- 기본 서버 1세트는 공짜라서 m명까지는 증설 0대
- `need = players[i] / m` (정수 나눗셈)이 필요한 증설 서버 대수
- 우선순위 큐에는 서버가 아니라 각 서버의 **종료 시간(i+k)** 을 넣는다
- 매 시각 i마다: 만료 서버 제거 → 현재 대수 확인 → 필요 대수 계산 → 부족분 추가
