# Algorithm

BaekjoonHub로 자동 업로드되는 백준/프로그래머스 알고리즘 풀이 저장소입니다. C++과 Python 풀이를 난이도와 문제별 폴더 구조로 관리합니다.

## 프로젝트 개요

이 저장소는 온라인 저지 문제 풀이를 누적 관리하기 위한 공간입니다. 문제별 `README.md`와 소스 파일이 함께 저장되어 있어, 풀이 기록과 제출 코드를 한 번에 확인할 수 있습니다.

## 저장소 구조

```text
.
├── README.md
├── 백준/
│   ├── Bronze/
│   ├── Silver/
│   └── ...
└── 프로그래머스/
    └── 난이도별 문제 폴더
```

각 문제 폴더는 보통 다음과 같은 구조를 가집니다.

```text
문제번호. 문제이름/
├── README.md
└── 풀이소스.cc 또는 풀이소스.py
```

## 사용 언어

- C++
- Python

## 풀이를 볼 때 확인할 점

- 문제별 README에서 문제 설명과 입출력 조건 확인
- 소스 파일에서 실제 제출 코드 확인
- 같은 유형 문제를 난이도별로 묶어 복습
- 시간 제한이 빡빡한 문제는 입출력 최적화 여부 확인

## 로컬 실행 예시

C++ 파일은 다음과 같이 컴파일해 실행할 수 있습니다.

```bash
g++ -std=c++17 solution.cc -o solution
./solution
```

Python 파일은 다음과 같이 실행할 수 있습니다.

```bash
python solution.py
```

## 학습 메모 작성 추천

자동 생성된 문제 README와 별도로, 어려웠던 문제에는 다음 내용을 추가하면 복습 효과가 좋습니다.

- 핵심 알고리즘
- 처음 틀린 이유
- 시간 복잡도
- 비슷한 문제 링크

## Notion 아카이브 복원분

일부 풀이는 BaekjoonHub 자동 업로드가 되지 않아 Notion 학습 노트 `🙃 알고리즘 공부`에만 남아 있었습니다. 이 풀이들을 저장소 구조에 맞춰 옮겨 왔습니다.

- 백준 19문제 (2024년 작성, C++)
- 프로그래머스 29문제 (2026년 작성, Python·C++·SQL)

복원분의 README에는 다음 차이가 있습니다.

- 채점 성능(시간/메모리) 정보가 없습니다. 제출 결과가 아니라 노트에 남은 코드이기 때문입니다.
- 대신 Notion에 적어 둔 풀이 메모와 재풀이 이력(같은 문제를 며칠에 걸쳐 다시 푼 기록)이 들어 있습니다.
- 코드는 공백만 정리했고 로직은 노트에 있던 그대로입니다.
